For testers

Try the Gemini Nano preview models

Last checked: 2026-09-25, against Google's official AICore Developer Preview page. Google may change these steps: if something differs, that page is the reference.

What this is

When AudioLens runs on-device, it uses Gemini Nano through Android's AICore system service. Google ships a tested Stable model to every compatible phone. Through the AICore Developer Preview, it also offers newer Preview models (such as Gemini Nano 4) before they reach everyone.

You don't need any of this to use AudioLens. The app always uses the Stable model for its guides. Preview models are only for testers who want to compare them in AudioLens's Nano Prompt Lab.

Before you start: pre-production models may be slower and less accurate than the Stable one, and the very first request can take about a minute. They may also affect your phone's stability, storage and performance. Only enroll a phone you're comfortable testing on.

Prerequisites

  • An Android phone that supports the ML Kit Prompt API (see Google's supported devices). Preview models also need an AI accelerator from Google, MediaTek or Qualcomm.
  • The Google account you use on that phone.
  • Wi-Fi for the model download, which is large.
  • AudioLens installed, with Gemini Nano available (Settings shows it as an AI provider).

Enable the preview models

  1. 1
    Join the Google group aicore-experimental with the Google account used on the phone.
  2. 2
    Become a tester of the Android AICore testing program.
  3. 3
    Update AICore: on the phone, open Settings, then Google, All services, System services, AICore, and tap Update when it's offered.
  4. 4
    Open the AICore app (its icon appears after the update) and accept the terms.
  5. 5
    Download a preview model: in the AICore app, open the model picker and select a preview version of Gemini Nano. The download needs Wi-Fi and takes several minutes.
  6. 6
    Pixel only, optional: turn on Bypass quota limits in the AICore app's settings to avoid BUSY errors when you run many tests.

Use it in AudioLens

  1. 1
    Open Settings > Tools > Nano Prompt Lab.
  2. 2
    Under Model, each option shows its status on your phone. Pick Preview · Fast or Preview · Full: Fast favors speed, Full favors accuracy.
  3. 3
    If the option says to download, tap Download this model. If it says unavailable, your phone isn't enrolled yet or doesn't support preview models.
  4. 4
    Run a free-form prompt or the full pipeline. Each result shows which model produced it, and the in-app logs record it too, so you can compare Preview and Stable on the same photo.

Your regular guides keep using the Stable model, whatever you pick in the lab.

Leave the program

  1. 1
    Tap Leave the program on the AICore testing page.
  2. 2
    In Settings, Google, All services, System services, AICore, uninstall the updates to go back to the production version.
