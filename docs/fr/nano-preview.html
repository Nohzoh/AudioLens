Pour les testeurs

Essayer les modèles Preview de Gemini Nano

Dernière vérification : 25/09/2026, d'après la page officielle de Google AICore Developer Preview (en anglais). Google peut modifier ces étapes : en cas de différence, c'est cette page qui fait foi.

De quoi s'agit-il ?

Quand AudioLens fonctionne sur l'appareil, il utilise Gemini Nano via le service système Android AICore. Google installe un modèle Stable, testé, sur tous les téléphones compatibles. Avec l'AICore Developer Preview, Google propose aussi des modèles Preview plus récents (comme Gemini Nano 4) avant leur sortie pour tous.

Rien de tout cela n'est nécessaire pour utiliser AudioLens. L'app utilise toujours le modèle Stable pour ses guides. Les modèles Preview servent seulement aux testeurs qui veulent les comparer dans le Nano Prompt Lab d'AudioLens.

Avant de commencer : les modèles de pré-production peuvent être plus lents et moins précis que le modèle Stable, et la toute première requête peut prendre environ une minute. Ils peuvent aussi affecter la stabilité, le stockage et les performances du téléphone. N'inscrivez qu'un téléphone sur lequel vous acceptez de faire des tests.

Prérequis

  • Un téléphone Android compatible avec l'API Prompt de ML Kit (voir les appareils compatibles). Les modèles Preview demandent en plus un accélérateur IA de Google, MediaTek ou Qualcomm.
  • Le compte Google utilisé sur ce téléphone.
  • Du Wi-Fi pour télécharger le modèle, qui est volumineux.
  • AudioLens installé, avec Gemini Nano disponible (il apparaît comme fournisseur d'IA dans les paramètres).

Activer les modèles Preview

  1. 1
    Rejoignez le groupe Google aicore-experimental avec le compte Google du téléphone.
  2. 2
    Devenez testeur du programme de test Android AICore.
  3. 3
    Mettez à jour AICore : sur le téléphone, ouvrez Paramètres, puis Google, Tous les services, Services système, AICore, et appuyez sur Mettre à jour quand c'est proposé.
  4. 4
    Ouvrez l'app AICore (son icône apparaît après la mise à jour) et acceptez les conditions.
  5. 5
    Téléchargez un modèle Preview : dans l'app AICore, ouvrez le sélecteur de modèle et choisissez une version Preview de Gemini Nano. Le téléchargement demande du Wi-Fi et prend plusieurs minutes.
  6. 6
    Pixel uniquement, facultatif : activez Bypass quota limits dans les paramètres de l'app AICore pour éviter les erreurs BUSY quand vous faites beaucoup de tests.

L'utiliser dans AudioLens

  1. 1
    Ouvrez Paramètres > Outils > Nano Prompt Lab.
  2. 2
    Sous Modèle, chaque option affiche son état sur votre téléphone. Choisissez Preview · Fast ou Preview · Full : Fast privilégie la vitesse, Full la précision.
  3. 3
    Si l'option indique à télécharger, appuyez sur Télécharger ce modèle. Si elle indique indisponible, votre téléphone n'est pas encore inscrit ou ne prend pas en charge les modèles Preview.
  4. 4
    Lancez un prompt libre ou le pipeline complet. Chaque résultat indique le modèle qui l'a produit, et les logs de l'app l'enregistrent aussi : vous pouvez comparer Preview et Stable sur la même photo.

Vos guides habituels continuent d'utiliser le modèle Stable, quel que soit votre choix dans le Lab.

Quitter le programme

  1. 1
    Appuyez sur Quitter le programme sur la page de test d'AICore.
  2. 2
    Dans Paramètres, Google, Tous les services, Services système, AICore, désinstallez les mises à jour pour revenir à la version de production.
